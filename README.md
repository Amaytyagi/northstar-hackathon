# NorthStar

A static landing page and interactive product prototype for a hackathon idea focused on helping first-time movers handle money, city life, and lifestyle pressure.

## Project files
- `landing.html` — startup landing page
- `app.html` — richer product dashboard prototype

## Open locally
Open either file directly in a browser:

- `landing.html`
- `app.html`

## GitHub Pages
This repository is set up as a public static site and can be served via GitHub Pages.

Example URLs:
- https://amaytyagi.github.io/northstar-hackathon/landing.html
- https://amaytyagi.github.io/northstar-hackathon/app.html

## Idea summary
NorthStar helps students and young adults moving to a new city for the first time:
- build a realistic budget
- track expenses
- detect impulse / lifestyle overspending
- reduce pressure to “show off”
- create a 90-day onboarding plan for a new environment

## Why this works for a hackathon
- real problem
- emotional + practical value
- strong demo experience
- easy to explain in under 2 minutes
